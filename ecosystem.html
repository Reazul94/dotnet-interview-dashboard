TESTING (xUnit / Moq) & DEVOPS CI/CD PIPELINES

AAA TESTING PATTERN (Arrange, Act, Assert)
[Fact]
public async Task GetCustomer_WhenExists_ReturnsOkResult()
{
    // 1. Arrange
    var mockRepo = new Mock<ICustomerRepository>();
    mockRepo.Setup(r => r.GetByIdAsync(10)).ReturnsAsync(new Customer { Id = 10 });
    var controller = new CustomerController(mockRepo.Object);

    // 2. Act
    var result = await controller.GetCustomer(10);

    // 3. Assert
    Assert.IsType<OkObjectResult>(result);
}

PRODUCTION INCIDENT TROUBLESHOOTING FRAMEWORK

1. Understand Impact → 2. Check Exception Logs → 3. Reproduce in non-prod → 4. Check recent deployments → 5. Inspect DB connections/deadlocks → 6. Identify Root Cause → 7. Apply workaround → 8. Validate fix → 9. Document RCA.
