# .NET / ASP.NET Core Interview — 1-Day Rapid Revision Dashboard

A practical, interactive single-page web application designed to help enterprise software developers (with Java/Spring/Oracle background) rapidly revise and excel in ASP.NET Core / .NET 8–10 senior engineering technical interviews.

## 🚀 Key Features

- **Candidate Positioning & Advantage Strategy**: Clear verbal scripts for bridging 4.5+ years of enterprise Java/Spring/Oracle experience to .NET.
- **Java → C# Knowledge Bridge Cheat Sheet**: Direct side-by-side mapping for 20 framework equivalents.
- **30 Core C# & OOP Accordion Cards**: Structured with definitions, real-world examples, C# code snippets, interview questions, and senior answers.
- **ASP.NET Core Core Architecture**: Middleware request pipeline flow visualizer, Kestrel web server mechanics, and Dependency Injection lifetime comparisons.
- **ADO.NET & Database Optimization**: High-priority ADO.NET objects revision and 12-step SQL query tuning checklist.
- **Interactive Practice Modes**: 10-question random Mock Interview practice mode, 3D Flashcard revision deck, live search filter, and `localStorage` progress tracking.
- **Fully Responsive Design**: Optimized desktop, tablet, and mobile layouts with touch-friendly navigation drawer.

## 🛠️ Usage

Simply open `index.html` in any web browser!

```bash
# Optional: Host locally using Python
python -m http.server 8080
```
Then open `http://localhost:8080` in your browser.
