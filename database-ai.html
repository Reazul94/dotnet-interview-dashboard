EXECUTION PLAN OPERATORS: INDEX SEEK vs INDEX SCAN

Q: What is the difference between Index Seek and Index Scan in SQL Execution Plans?
"Index Seek uses the B-Tree structure of an index to navigate directly to the exact matching rows (O(log N) fast binary lookup). Index Scan reads through all pages of the index from top to bottom (O(N) full table/index traversal). You should optimize queries to perform Index Seeks wherever possible!" Index Seek বি-ট্রি ব্যবহার করে সরাসরি নির্দিষ্ট সারিতে যায় (খুব দ্রুত O(log N))। Index Scan পুরো ইনডেক্স স্ক্যান করে (ধীরগতির O(N))।
Q: What is SARGability and Covered Index?
"SARGable (Search Argument Able) means a query condition can utilize an index. Wrapping an indexed column inside a SQL function like WHERE YEAR(OrderDate) = 2024 makes it non-SARGable (causing Index Scan). Rewrite it as WHERE OrderDate >= '2024-01-01' AND OrderDate < '2025-01-01'. A Covering Index includes all requested columns in its leaf nodes via INCLUDE (Col1, Col2) to eliminate Key Lookups." SARGable কুয়েরি ইনডেক্স ব্যবহার করতে পারে। কলামের উপর ফাংশন দিলে ইনডেক্স কাজ করে না। Covered Index `INCLUDE` কি-ওয়ার্ড দিয়ে Key Lookup দূর করে।

TRANSACTIONS, LOCKING & SNAPSHOT ISOLATION (RCSI)

Q: How do you resolve Database Deadlocks and Blocking in enterprise applications?
"1. Access database tables in identical chronological order across all Stored Procedures.
2. Keep transactions short and focused; never execute external REST API HTTP calls inside a database transaction block.
3. Enable READ_COMMITTED_SNAPSHOT (RCSI) in SQL Server. RCSI uses Row Versioning in tempdb so readers do not block writers and writers do not block readers!" ১. টেবিল একই ক্রমানুসারে অ্যাক্সেস করুন। ২. ডাটাবেজ ট্রানজেকশনের ভেতরে REST API কল করবেন না। ৩. RCSI অন করলে রিডার ও রাইটার একজন অন্যজনকে ব্লক করে না।

🤖 .NET 8 / 9 / 10 AI ARCHITECTURE & SEMANTIC KERNEL

What is Microsoft Semantic Kernel?
Microsoft Semantic Kernel is an open-source SDK that enables .NET developers to easily integrate OpenAI, Azure OpenAI, HuggingFace, and custom LLM models into C# enterprise applications. It orchestrates AI Plugins, Native Functions, Prompt Templates, and Vector Memory. Semantic Kernel হলো মাইক্রোসফটের C# SDK যা OpenAI/Azure OpenAI মডেলকে এন্টারপ্রাইজ অ্যাপে প্লাগইন ও মেমরির সাহায্যে যুক্ত করতে ব্যবহৃত হয়।
C# SEMANTIC KERNEL INITIALIZATION SNIPPET
using Microsoft.SemanticKernel;

var builder = Kernel.CreateBuilder();
builder.AddOpenAIChatCompletion(
    modelId: "gpt-4o",
    apiKey: builder.Configuration["OpenAI:ApiKey"]
);

Kernel kernel = builder.Build();
var result = await kernel.InvokePromptAsync("Summarize ERP gas billing anomaly for Customer ID #9481");
Console.WriteLine(result.GetValue<string>());

🧠 RAG (RETRIEVAL-AUGMENTED GENERATION) & VECTOR DATABASES

1. Document Ingestion: Extract text from PDFs, database logs, or enterprise policies.

2. Text Chunking: Split content into semantic blocks (e.g. 500 tokens with 50-token overlap).

3. Vector Embeddings: Generate numeric floating-point vectors via embedding models (e.g. text-embedding-3-small).

4. Vector Store Search: Query vector databases (pgvector, Azure AI Search, Qdrant) using Cosine Similarity / HNSW index.

5. Contextual Completion: Inject retrieved chunks into LLM system prompt to generate grounded, hallucination-free answers.

TOP 10 AI-RELATED .NET INTERVIEW QUESTIONS & MODEL ANSWERS

Q1: How do you integrate OpenAI / LLM APIs securely in ASP.NET Core without leaking API keys?
"Never hardcode API keys in code or appsettings.json. Store keys in Azure Key Vault or Environment Variables. Inject IHttpClientFactory or Microsoft's unified IChatClient interface in .NET 9 with proper resilience policies (Polly retry & rate limiting)."
Q2: What is the difference between Fine-Tuning an LLM vs using RAG for enterprise search?
"Fine-tuning retrains model weights to learn specific style or domain terminology, but is expensive and cannot handle rapidly changing real-time data. RAG retrieves fresh context dynamically from enterprise databases or Vector Stores and passes it into the prompt, making it ideal for ERP & billing documentation."
Q3: How do you handle Prompt Injection and SQL Injection when using AI agents to generate database queries?
"Never execute raw SQL generated by LLMs directly with admin privileges! Validate LLM-generated SQL against a strict read-only parser, execute using a restricted read-only database user account, enforce parameterization, and wrap AI tools in safe C# native functions."
Q4: What is Function Calling / Tool Calling in Semantic Kernel?
"Function Calling allows an LLM to decide when to invoke a native C# method (e.g. [KernelFunction] get_customer_balance(int id)). The LLM returns structured JSON arguments, the C# runtime executes the method against SQL/Oracle, and returns the result back to the LLM."
Q5: How do you handle streaming responses from LLM APIs in ASP.NET Core?
"Use C# 8+ IAsyncEnumerable<string> with Server-Sent Events (SSE) or WebSockets in ASP.NET Core controllers so tokens are streamed incrementally to the client as generated by the LLM without waiting for the full response payload."
Q6: What is pgvector and how does it fit into relational SQL databases?
"pgvector is an open-source extension for PostgreSQL that enables storing vector embeddings alongside traditional relational table columns, allowing hybrid search (combining SQL WHERE clauses with vector semantic similarity search)."
Q7: How do you monitor and track LLM token usage and latency in .NET?
"Use OpenTelemetry instrumentation built into .NET 9 AI extensions. Monitor prompt tokens, completion tokens, and HTTP request latency using Application Insights or Prometheus/Grafana dashboards."
Q8: How can AI be applied to automatically detect database performance bottlenecks?
"AI agents can analyze SQL Server Query Store DMV data, identify high-reads or missing index recommendations, and draft optimized index DDLs or execution plan rewrites for DBA review."
Q9: What is Microsoft's new Microsoft.Extensions.AI package in .NET 9?
"It is a standard unified set of C# abstractions (e.g. IChatClient, IEmbeddingGenerator) provided by Microsoft so .NET applications can switch between OpenAI, Azure AI, Ollama, or local Llama models with zero code rewrite."
Q10: What is your response strategy if asked about AI experience in a technical interview?
"Say: 'My primary enterprise foundation is in robust backend API engineering, SQL tuning, and ERP workflows, but I actively leverage modern AI tooling in .NET—such as Semantic Kernel, RAG patterns, vector embeddings, and LLM tool calling—to build intelligent enterprise applications.'"
